# Basiscontrole

Controleer eerst in Home Assistant:

1. Binnen- en buitenunit zijn online.
2. Temperatuursensoren geven plausibele waarden.
3. Systeem staat niet in noodbedrijf.

Controleer daarna op [Instellingen - Algemeen](./configuratie-algemeen.html):

1. `switch.dhw_enabled_switch` staat goed voor jouw installatie.
2. Sensor offsets staan alleen aangepast als daar reden voor is.
3. `switch.emergency_mode_enabled` staat uit.

Volgende stap: [Verwarmen instellen](./verwarmen.html).
