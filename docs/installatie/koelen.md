# Koelen (optioneel)

Open [Instellingen - Koelen](./configuratie-koelen.html).

1. Kies `select.cool_mode_select`.
2. Gebruik `number.cooling_setpoint_number` bij intern setpoint.
3. Gebruik `number.manual_setpoint` bij extern setpoint.
4. Gebruik dauwpuntbeveiliging in Home Assistant voor veilige aansturing.

Volgende stap: [SmartGrid (optioneel)](./smartgrid.html).
